Data files used by the package.

  catalogue.csv                      planet parameters from the
  provenance.json                    NASA Exoplanet Archive, with the
                                     date they were downloaded

  throughput_instruments.npz         measured instrument efficiencies
                                     (GIANO, CARMENES, SPIRou)

  transmission_airmass1_pwv2.5.npz   Earth atmosphere transmission

Refresh the catalogue with `python cli.py --refresh-catalogue`.
